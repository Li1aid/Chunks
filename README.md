# Chunks

Chunks is a native SwiftUI language-learning app that turns a Chinese sentence
into natural English, extracts reusable phrases, and schedules them as
spaced-repetition flashcards.

## Highlights

- Chinese-to-English translation with reusable phrase extraction
- FSRS-based review scheduling
- Personal phrase library and speech playback
- Optional cloud sync
- Credentials entered in Settings and stored in the Apple Keychain

## Run locally

1. Open `Chunks.xcodeproj` in Xcode.
2. Select your own Development Team under Signing & Capabilities.
3. Build for an iPhone, iPad, Mac, or simulator.

No API keys, app tokens, or personal learning data are committed to this
repository.
